
How to convert the super cell into the dia shaped cell.

1. open the file 'fig6_tdwg.vasp' with VESTA
2. Edit -> Edit Data -> Unit Cell...
3. choose 'Transform...' button
4. Input the following numbers in the
   'Rotation matrix P' (3x3) as
     1    0.5    0
     0.5  0.5    0
     0    0      1
 5. choose 'OK' button
    -> Yes -> Apply -> OK
